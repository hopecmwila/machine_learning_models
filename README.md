# Machine Learning
This repository contains data and code that was used to learn data cleaning, processing and 
model training using the Titanic Dataset

## Layout
**Titanic-Dataset.csv:** this is the original raw dataset containing the passengers' information.

**Titanic.ipynb:** This is the Jupyter notebook containing details on the data cleaning, processing and
training.

**titanic_cleaned.csv:** this is the cleaned version of the titanic dataset after handling missing values.

## Requirements
You need Python and the following data science libraries installed:
- pandas: used to clean messy tabular datasets, read and clean csv files.
- numpy: used to handle large mathematical arrays and perform fast numerical operations.
- matplotlib: used to create static data visualisations.
- scikit-learn: used to build machine learning models.
